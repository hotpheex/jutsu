# Global agent instructions

Harness-neutral instructions that apply in every repo and every session. Claude
Code loads this through `claude/CLAUDE.md`; Codex reads it directly from
`~/.codex/AGENTS.md`. Both are symlinks into `~/.jutsu` made by `link.sh`.

Keep this file short and general. Anything specific to one repo belongs in that
repo's own `AGENTS.md`. Anything specific to one harness belongs in
`claude/CLAUDE.md` (or the equivalent for that harness).
